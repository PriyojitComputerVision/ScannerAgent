ScopeGuard MCP tools

Agents reach the scanner through ten MCP tools. Every tool call goes through the same shared rules (ScanService) as the console and A2A, so an agent can only do what the operator allowed, and a person approves every scan.

Rules on every call · scan_service.py
  • target on the operator allowlist
  • authorization_confirmed must be true
  • only the four pentest profiles
  • RBAC roles, owner-only scans
  • credentials by profile name, never returned
  • one scan at a time
  • output wrapped as untrusted data
  • every call logged, every refusal audited
  • tools switched off: MCP_DISABLED_TOOLS
  • code uploads: .zip only, scan:source
  • site text to the LLM: wrapped, never obeyed
