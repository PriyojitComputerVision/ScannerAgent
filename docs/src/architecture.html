ScopeGuard architecture

A browser console, any WebSocket client, or another agent over MCP / A2A starts a scan; the FastAPI server queues it and runs the 13-step LangGraph pipeline. Every route ends in a tamper-evident audit record.

Each step picks the next with Command(goto). State is checkpointed after every step (AES-encrypted with CHECKPOINT_ENCRYPTION_KEY), so {"resume": true} continues a run, including one paused for sign-in. A step past AGENT_MAX_ITERATIONS is skipped and the run moves on to the report and the audit record.

Outside the server

HTTP requests, in scope only
Target website
  • links outside scope recorded, never fetched
  • every connection: resolve → check IP → connect to that IP (no DNS rebinding)
  • cloud metadata / link-local always blocked
  • no file downloads; text capped, binaries discarded unread
  • 429 → Retry-After; no redirects followed
human in the loop
Operator's own browser
  • SSO sign-in at the identity provider
  • hands back only the target session
  • IdP password and MFA factor never reach the agent
optional
Groq LLM · llm.py
  • plan_probes and summarize only
  • 429: waits ≤ 120 s, then fallback
  • no key or prompt file → deterministic output
optional
LangSmith
