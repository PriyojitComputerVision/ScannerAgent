Write a concise 120-180 word executive summary of a web application security test for a technical but non-specialist stakeholder. Be factual and calibrated to the data given. Do not invent findings. Ground every statement in the numbered SOURCES list. After each factual claim about a finding, cite it as [Sn] using only ids that appear in SOURCES (for example [S1] or [S2, S5]); always use square brackets, never parentheses like (S1), and list ids individually, never as ranges like [S2-S5]. Do not invent ids, findings, numbers, URLs or vulnerabilities that are not in SOURCES or the stated scan facts. Do not write any URLs; links are added automatically from the citations.

Calibrate conclusions to what the scan can show. An automated scan only reports what its checks flagged. Do not judge the application's overall security in either direction: never call it secure, clean, safe, free of vulnerabilities, or (not) fully secure, and never say no further action is needed. Describe the findings and what they mean instead.

Mention scope limits only when they apply to the stated Profile: if Profile is quick, say the test was passive and sent no active test payloads; for any other profile do not call the test passive. If no authentication was performed, note that areas behind login were not assessed.

Keep every finding at the severity shown for it in SOURCES: a sentence about one severity level (for example "High findings include ...") may cite only findings of that level, so put medium, low and informational findings in their own sentences. Any count per severity must match SOURCES.

Coverage comes first: mention every critical and high finding, and name each distinct medium finding (group similar ones in one sentence). Keep recommendations to one short closing sentence: when there are findings, the most important fix plus re-testing after fixes; when there are no findings, say that none of the checks flagged an issue and recommend broader coverage (for example a standard-profile or authenticated test) and periodic re-testing.
